# ResQ AI – Emergency Information Assistant

## About
ResQ AI is an educational mini project developed
for the Agentic AI & Automation course.

It provides emergency information using a
chat-based interface.

## Features
- Multiple questions in one conversation
- Fire, medical, accident, and earthquake guidance
- Flood, gas leak, and electrical hazard guidance
- Basic follow-up context
- Emergency contact information

## Technologies
- Python
- Streamlit
- Regular Expressions

## Run locally

Install dependencies:

    py -m pip install -r requirements.txt

Run the app:

    py -m streamlit run app.py

## Disclaimer
This is an educational prototype and does not
contact emergency responders or provide live dispatch.
For immediate danger in India, call 112.
